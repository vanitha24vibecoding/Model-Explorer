# Model Explorer: product design case study

A portfolio case study for Model Explorer in Microsoft Fabric Planning, focused on designing **Freeze Columns**.

## Files

- `index.html`: the case study page
- `assets/img/`: screenshots, user flow and profile photos
- `media/`: the walkthrough video and its poster image

## Publish with GitHub Pages

1. Upload all files to a repository, keeping the folder structure.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute or two, the page is live at `https://<your-username>.github.io/<repository-name>/`.

To preview locally, open `index.html` in a browser.
